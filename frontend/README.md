# 二手数码交易平台与智能质检辅助系统(前端)

毕业设计项目「二手数码交易平台与智能质检辅助系统」的前端工程。

## 技术栈

- Vue 3 + TypeScript + Vite
- Element Plus
- Pinia / Vue Router
- UnoCSS / SCSS

## 快速开始

```bash
pnpm install
pnpm dev
```

生产构建:

```bash
pnpm build:prod
```
